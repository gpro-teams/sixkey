Deleting the test passkey

A web page cannot delete a passkey. Remove sixkey-probe-delete-me yourself:

  • macOS: the Passwords app › Passkeys (macOS 14: System Settings › Passwords), and chrome://password-manager/passwords if Chrome saved it in Google Password Manager or the Chrome profile.
  • Windows: Settings › Accounts › Passkeys, and chrome://password-manager/passwords if it was saved in Google Password Manager.

Then remove this extension in chrome://extensions.
